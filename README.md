# Proyecto Final

## Descripción

Proyecto desarrollado como parte de la actividad final, organizado
por bloques de trabajo.

## Estructura del proyecto

### Bloque 1 - Review
Contiene la revisión y análisis realizado durante el bloque 1.

### Bloque 2 - Estrategia
Contiene la estrategia definida para el desarrollo del proyecto.

### Bloque 3 - Arquitectura
Contiene la propuesta y documentación de la arquitectura del sistema.

### Bloque 4 - Documentación
Contiene la documentación general y los ADR correspondientes.

### Bloque 5 - Base de datos
Contiene la revisión de la base de datos y el script SQL utilizado
para crear las tablas y relaciones.

## Tecnologías utilizadas

- SQL / MySQL
- Vue.js
- JavaScript / TypeScript
- Git / GitHub

## Base de datos

El bloque 5 contiene:

- DB_REVIEW.md
- Script SQL
- Estructura de las tablas
- Relaciones y restricciones

## Organización

Cada bloque se encuentra en su propia subcarpeta para facilitar la
revisión de los entregables.
